Rainy Getaway

A place to help you Get-Away from bad weather!

  • Call to action!
  • Main Page!
  • Form Page!

Project Description

This website will provide real-time and up-coming weather information of famous cities displayed on a list, where you are able to click their respective card to learn more through the use of modal technologies, this website will get its latitude and longitude of each city through reading a separate JSON file, the index page will be a call to action with basic information to invite people to use the website, the main page will have the program previously described and the third page will be a form where you are able to input latitude and longitude information and generate a fourth page with current and up-coming weather information of any city! Simple animations on page load will also be added.

The "cards" will display the weather for today and the next 2 days, but by clicking them you will be able to see 5 days of weather forecast, buttons to filter the cards by weather will also be included

Scenarios

How does the filter works?

The filter takes in consideration only the first 3 days of forecast, if the weather you are filtering for is present today, tomorrow or the day after, the filter will add it and display it when clicked, meaning if you happen to have a rain-cloudy-sunny streak, it will appear on all 3 filters

How is the weather forecast collected?

The weather is collected and displayed through an openweathermap API call, displaying forecast information from the closest weather station to the displayed city
